إعدادات Firebase Web

أدخل إعدادات تطبيق Firebase Web الخاص بك. لا تستخدم إعداد Android أو ملف google-services.json. توجد هذه القيم في Firebase Console → Project Settings → General → Your apps

💡 نصيحة: هذه البيانات تحفظ في متصفحك فقط (localStorage) ولا ترتفع لأي سيرفر. إذا بدلت المتصفح أو مسحت الكاش، رح تحتاج تعيد إدخالها.
