# Store assets

This directory contains only the store assets that actually exist in the repository. Do not add placeholder images just to satisfy a checklist; exports must come from the approved channel logo.

- `feature-graphic.png` — Play Store feature graphic, 1024×500
- `README-preview.png` — quick visual summary for maintainers

Available:

- `icon-512.png` — exported from the official 1024×1024 channel logo
- `icon-1024.png` — exported from the official 1024×1024 channel logo

Not currently present:

- Screenshots — no Android screenshots are committed; capture them from the actual Kotlin app after building and running it

The app is Android-only (Kotlin/Jetpack Compose). These assets must not imply HD or continuous 24/7 live streaming when that feature is not enabled.
