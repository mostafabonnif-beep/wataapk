# V10 — Web-only Administration

The embedded Android admin console has been removed.

## Consumer app
- No admin login.
- No admin PIN/secret gesture.
- No admin dashboard/dialog.
- Settings contains consumer preferences, support, official information and version details only.

## Web Control Center
The existing `admin/` Firebase web console remains the administration surface for:
- live streams
- YouTube/social content
- websites
- archive
- EPG
- banners
- breaking news
- app configuration
- security/telemetry

This separation keeps the Android TV application focused on viewers and keeps privileged operations out of the consumer UI.
