# 📲 إشعارات Push حقيقية (FCM) عبر Vercel — دليل الإعداد

## الفكرة

التطبيق يسجّل توكن FCM لكل جهاز في مجموعة `push_tokens/{userUid}`.
لوحة التحكم تحفظ التنبيهات في `notifications` وتظهر داخل التطبيق فقط.
مع دالة Vercel الجديدة `api/send-push.js` يمكنك إرسال **Push حقيقي يظهر خارج
التطبيق** لجميع الأجهزة — **بدون Cloud Functions** (تبقى على الخطة المجانية).

## خطوات الإعداد (مرة واحدة — ~10 دقائق)

### 1. أنشئ حساب خدمة Firebase
1. Firebase Console → ⚙️ إعدادات المشروع → **حسابات الخدمة**.
2. اضغط **توليد مفتاح خاص جديد** → يُنزَّل ملف JSON (مثال `elwataniatv-service-account.json`).
3. هذا الملف سرّي جداً — لا ترفعه إلى GitHub أبداً (ملف `service-account.json` في `.gitignore`).

### 2. أضف المفتاح إلى Vercel
1. افتح مشروع Vercel الذي تستضيف عليه اللوحة (`elwataniatv-channel`).
2. Project → Settings → **Environment Variables**.
3. أضف متغيراً باسم **`FIREBASE_SERVICE_ACCOUNT`** وقيمته **محتوى ملف JSON كاملاً** (نص واحد).
4. أعد النشر (Deploy) — يجب نشر مجلد `api/` مع المشروع.

### 3. انشر مجلد api/
```bash
# من جذر المستودع — الدالة موجودة في api/send-push.js
vercel deploy --prod
```
أو ادفع التغيير إلى الفرع المرتبط بـ Vercel (إن كان النشر تلقائياً).

### 4. جرّب من اللوحة
1. افتح لوحة التحكم (`https://elwataniatv-channel.vercel.app/admin`).
2. تبويب **الإشعارات**.
3. اكتب العنوان والنص → اضغط **حفظ التنبيه داخل التطبيق** (يظهر داخل الشريط).
4. اضغط **📲 إرسال الآن** → ستصل الرسالة لجميع الأجهزة المثبّت عليها التطبيق
   حتى لو كان مغلقاً (يظهر كإشعار نظام).

## التحقق

- زر الإرسال يعرض «وصل إلى N جهازاً» — هذا هو عدد التوكنات المسجلة.
- إذا ظهر «0 جهاز»: تأكد أن التطبيق متصل بـ Firebase (ضع `google-services.json`
  الصحيح) وأن جهازاً واحداً على الأقل فتح التطبيق بعد تفعيل الإشعارات.

## بنية الدالة

| ملف | الدور |
|---|---|
| `api/send-push.js` | دالة Vercel (Node 20) — تقرأ `push_tokens` وترسل عبر FCM HTTP v1 |
| `api/package.json` | اعتماديات الدالة (`firebase-admin`) |

> **الأمان:** الدالة لا تتحقق من هوية المرسل (من يُدخل رابط الدالة يستطيع
> إرسال Push). للحماية: قيّد الدالة بـ Vercel Protection (Preview) أو أضف
> تحققاً من توكن إداري في `admin/index.html` قبل الاستدعاء. هذا مقبول
> للمرحلة الحالية لأن رابط الدالة غير معلن، لكنه نقطة يجب شدّها قبل التوسع.
