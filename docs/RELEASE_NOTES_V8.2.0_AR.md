# ملاحظات الإصدار v8.2.0 — الوطنية TV

**التاريخ:** 23 أغسطس 2026 · **versionCode 33**

إصدار التلميع الاحترافي: إصلاحات بناء، تحسينات جودة عربية، وتحديثات توافق مع متجر Play.

## ✅ الإصلاحات والتحسينات

### البناء والإصدار
- **إزالة تعطّل بناء Release بدون google-services.json**: أصبح `assembleRelease` يبني APK موقعاً للتجربة الداخلية مع تحذير واضح (يعمل التطبيق بالبيانات المحلية)، بينما يبقى `bundleRelease` (رفع Play Store) مشروطاً بملف Firebase الحقيقي حمايةً من النشر الصامت غير المتصل.
- **إصلاح تبديل اللغة داخل App Bundle**: تفعيل `language.enableSplit = false` — بدون هذا الإصلاح كان تبديل العربية/الإنجليزية داخل التطبيق يفشل في حزم AAB على Play لأن ملفات اللغات تُقسَّم ولا تُحمَّل دون Play Core.
- **قواعد نسخ احتياطي صريحة (Android 12+)**: إضافة `data_extraction_rules.xml` تمنع نسخ بيانات التطبيق السحابي ونقلها بين الأجهزة (توكنات FCM ومعرّف التثبيت والمحتوى المحلي).

### الهوية البصرية
- **أيقونة Theme ثيمات Android 13+**: إضافة طبقة `monochrome` (ظل أحادي لشعار القناة) تتلون تلقائياً مع ثيم أيقونات النظام (Themed Icons).
- **ثيم إقلاع داكن**: استبدال ثيم الإقلاع الفاتح بثيم داكن مطابق للخلفية الكحلية — لا وميض أبيض عند فتح التطبيق من البرد.

### جودة النصوص العربية
- **تحويل العدّادات إلى صيغ الجمع العربية الصحيحة (Plurals)** في: المواقع، المنصات، الإشعارات (المتاحة وغير المقروءة)، برامج الأرشيف، والدقائق المتبقية من EPG — مع التفريق الصحيح بين «موقع واحد / موقعان / 3 مواقع / 11 موقعاً».

## 📦 البناء

```bash
./gradlew assembleDebug        # APK تجريبي
./gradlew assembleRelease      # APK إصدار (يشتغل ببيانات محلية دون Firebase)
./gradlew test lint            # الاختبارات والفحص
```

> **ملاحظة:** لتفعيل البث والإشعارات من لوحة التحكم Firebase، ضع `app/google-services.json` الخاص بمشروعك ثم أعد البناء.
