# ملاحظات الإصدار v8.6.0 — الوطنية TV

**التاريخ:** 10 سبتمبر 2026 · **versionCode 38**

إصدار مرشح نهائي يركز على تشغيل الأرشيف داخل التطبيق، استئناف المشاهدة، ثبات البث، وتحسين قابلية الاستخدام في RTL ولوحة التحكم.

## ✅ تجربة المشاهدة

- تشغيل فيديوهات الأرشيف داخل التطبيق بدل الاعتماد على المتصفح الخارجي.
- تحويل روابط YouTube المختصرة وروابط `watch` و`shorts` إلى صيغة تشغيل ثابتة.
- رفض الروابط غير الصالحة برسالة واضحة بدل فتح مشغل فارغ.
- دعم الصور المصغرة من رابط الفيديو مع صورة احتياطية عند غيابها.
- حفظ موضع المشاهدة والمدة كل خمس ثوانٍ.
- استئناف الفيديو من آخر موضع محفوظ، مع إعادة التشغيل من البداية عند الوصول إلى النهاية.
- إضافة قسم «تابع المشاهدة» مع شريط تقدم وصورة مصغرة.
- تحسين حالات التحميل والفشل وإعادة الاتصال واختيار مصدر Firestore احتياطي نشط فقط.
- تحسين مشغل YouTube داخل WebView: قبول ملفات الارتباط، التقاط أخطاء التحميل والمهلة، وإظهار زر فتح خارجي بدلاً من شاشة سوداء صامتة.

## ✅ التصميم والوصول

- تكبير مناطق لمس أزرار البث والأرشيف لتناسب الهاتف.
- تحسين بطاقات الأرشيف ووضوح الحالة والتصنيف ووقت الإضافة.
- تحسين شريط التنقل RTL في لوحة التحكم مع قائمة جانبية للشاشات الكبيرة.
- إضافة حالات فارغة وخطأ وتحديث واضحة في لوحة التحكم.
- استمرار دعم العربية والفرنسية والإنجليزية دون تغيير قواعد البيانات أو الصلاحيات.

## 🧪 التحقق

تم التحقق من:

```bash
./gradlew testDebugUnitTest
./gradlew lintDebug
./gradlew assembleDebug
npm test --prefix functions
npm test --prefix rules-tests
node scripts/build-hosting.js
```

النتائج: اختبارات Android وFunctions وFirestore Rules ناجحة، واختبارات قواعد Firestore **30/30** ناجحة، وبناء APK التجريبي وHosting ناجحان.

## ⚠️ قبل النشر النهائي

هذا مرشح الإصدار من المصدر. إصدار Play Store النهائي يحتاج إلى بناء AAB موقّع بمدخلات التوقيع المحمية و`google-services.json` الإنتاجي، ثم اختبار على جهاز Android حقيقي قبل النشر. لا توجد أسرار أو مفاتيح توقيع داخل المستودع.
