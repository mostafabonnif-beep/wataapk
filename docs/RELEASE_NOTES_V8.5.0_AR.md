## 🆕 دليل البرامج الكامل (Program Guide)
- **شاشة دليل جديدة كاملة**: كل برامج اليوم في قائمة واحدة قابلة للتمرير
  (سابقاً كان يظهر برنامجان فقط في الشريط الرئيسي).
- **اختيار اليوم**: أمس / اليوم / غداً (بتوقيت الجزائر) مع عرض التاريخ.
- **تمييز البرنامج الحالي**: شارة حمراء «يعرض الآن» + إبراز الحدود.
- **حالة البرامج**: البرامج المنتهية تتلاشى، البرامج القادمة كاملة الوضوح.
- **حوار تفاصيل البرنامج**: العنوان، التصنيف، الوقت، المدة، الوصف،
  وتفعيل/إلغاء التنبيه مباشرة.
- **مداخل**: شاشة البث المباشر (زر «دليل البرامج») + بطاقة جديدة في «المزيد».

## 🆕 خط Cairo الاحترافي
- خط **Cairo** (Google Fonts — رخصة OFL) بأوزانه الخمسة (400/500/600/700/900)
  بدل خط النظام الافتراضي — هوية بصرية أقوى للعربية واللاتينية مع الحفاظ
  على دعم RTL الكامل على كل إصدارات أندرويد (minSdk 24).
