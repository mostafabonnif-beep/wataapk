## التوزيع العام

بقي مستودع GitHub خاصاً لحماية المصدر. لذلك نُشرت صفحة التحميل العامة وملف APK عبر Firebase Hosting: [`https://elwataniatvapp.web.app/download`](https://elwataniatvapp.web.app/download). لأن Firebase Hosting على خطة Spark لا يقبل ملفات APK التنفيذية مباشرة، يحوّل سكربت `scripts/build-hosting.js` APK إلى Base64 داخل ملف نصي، وتعيد صفحة التحميل بناء الملف محلياً عند ضغط المستخدم. تم تنزيل payload المنشور وفكّه ومقارنة SHA-256، وكانت النتيجة مطابقة للـAPK الموقّع.

## فحص التشغيل

لم يظهر Crash خاص بحزمة التطبيق خلال فحص بدء التشغيل السابق. غير أن محاكي الخادم `elwatania-lite35` لم يسمح بتثبيت APK بسبب استثناء داخل `StorageManagerService.allocateBytes` في Android PackageManager على بيئة خادم بلا KVM. هذا فشل في بيئة الاختبار، وليس دليلاً على خطأ داخل التطبيق؛ لذلك لا يُعد بديلاً عن اختبار الجهاز الحقيقي.
