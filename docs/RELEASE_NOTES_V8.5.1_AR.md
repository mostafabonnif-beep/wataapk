# ملاحظات الإصدار v8.5.1 — الوطنية TV

**التاريخ:** 30 أغسطس 2026 · **versionCode 37**

إصدار إصلاحي صغير يعالج حالة حقيقية تكسر جدول البرامج عند الإدخال بلوحة مفاتيح عربية.

## ✅ الإصلاحات

### جدول البرامج (EPG)
- **دعم الأرقام العربية المشرقية (٠-٩) والفارسية (۰-۹) في أوقات ومدد البرامج**: عند إدخال المسؤول وقت برنامج مثل `٢٠:٣٠` أو مدة مثل `٦٠ دقيقة` من لوحة مفاتيح عربية، كان تحليل الوقت يفشل silently ويختفي معه «البرنامج الحالي» والعدّ التنازلي وشريط التقدّم والتذكيرات. أصبح `EpgTime` يطبّع الأرقام إلى ASCII قبل التحليل.
- **قبول النقطتين العرضيتين `：` ورمز النسبة `∶`** كفاصل وقت إضافي للنقطتين العاديتين — تظهران عند الكتابة من بعض لوحات المفاتيح.
- تنظيف حقول الساعة والدقيقة من الفراغات الزائدة قبل التحويل.

## 🧪 الاختبارات

أربعة اختبارات وحدة جديدة في `EpgTimeTest` تغطي:
- تحليل الأوقات بالأرقام العربية المشرقية (`٢٠:٣٠`).
- تحليل الأرقام الفارسية والنقطتين العرضيتين.
- تحليل المدد بالأرقام العربية (`٦٠ دقيقة`).
- عمل «البرنامج الحالي» والدقائق المتبقية مع بيانات عربية الأرقام بالكامل.

## 📦 البناء

```bash
./gradlew testDebugUnitTest   # اختبارات الوحدة
./gradlew assembleDebug       # APK تجريبي
```

لا تغيير في الصلاحيات أو قواعد Firestore أو واجهات البيانات — التحديث آمن للنشر فوق v8.5.0.
